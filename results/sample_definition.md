## How the rules were read where the text leaves room

- Stale days use one-minute returns between consecutive bars (exactly one minute apart) outside the excluded window; a pair that straddles a gap or the window is not a one-minute return.
- The bounce-back filter runs on all bars before the window is excluded and before the sample is cut, so the first days of the sample have their past days. It needs 20 trading days of history; on the first 20 days of a file nothing is flagged (counted below). It is one pass: a flagged bar is removed after all bars were judged on the original returns. A return is reversed by at least 75% if the next one-minute return has the opposite sign and at least 75% of its size (an overshoot counts). The next bar must lie on the same server day, so the last minute of a day is not judged and the data of a day do not depend on later days. A robust SD of zero is applied as written (any reversed move is then flagged); the count is shown.
- A day with bars only inside the excluded window has no price and counts as a short day.
- 'Day' means server calendar day; there are no Sunday bars on this server.
